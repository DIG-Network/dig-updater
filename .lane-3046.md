# Lane #3046 — a release must make the feed regenerate

dig_ecosystem#3046. The stable feed at updates.dig.net/v1/stable/manifest.json only
regenerates on a 6-hour cron, so a freshly released component is invisible to every
beacon for up to 6 hours. Measured: three manual `gh workflow run feed.yml` dispatches
were needed in one day.

Building: a drift check (released version vs the version the live feed actually serves)
that runs frequently, reddens on drift, and self-heals by dispatching feed.yml.
